# 📋 Changelog

All notable changes to **Terminator** are documented here.

## 🚀 Unreleased / Development

### ✨ Added

* 🧹 **All Session Clear Support**

  * Added support for clearing all terminal sessions at once.
  * [`ed15bbc`](https://github.com/8dmusichannels-star/terminator/commit/ed15bbc)

* ⌨️ **Physical Keyboard Support**

  * Added support for physical keyboards.
  * Improved keyboard interaction with the terminal.
  * [`0d7ef4d`](https://github.com/8dmusichannels-star/terminator/commit/0d7ef4d)

* 📸 **Photo Session Support**

  * Added photo session support.
  * [`4e81c40`](https://github.com/8dmusichannels-star/terminator/commit/4e81c40)

* ⌨️ **Split-Screen Keyboard Actions**

  * Added keyboard actions for split-screen IMEI usage.
  * Improved split-screen interaction.
  * [`4e81c40`](https://github.com/8dmusichannels-star/terminator/commit/4e81c40)

### 🎨 Improved

* ⚙️ **Display Settings Toggle**

  * Updated the Display Settings toggle behavior and UI.
  * [`ed15bbc`](https://github.com/8dmusichannels-star/terminator/commit/ed15bbc)

* 🛠️ **Toolbar UI**

  * Updated the toolbar UI.
  * Updated the native Android bubble toolbar.
  * [`0d7ef4d`](https://github.com/8dmusichannels-star/terminator/commit/0d7ef4d)

* 🖥️ **Split-Screen Experience**

  * Improved split-screen focus handling.
  * Improved split-screen session behavior.
  * [`1c14637`](https://github.com/8dmusichannels-star/terminator/commit/1c14637)

* ⌨️ **IMEI / Virtual Keyboard**

  * Improved virtual keyboard open/close behavior in split-screen mode.
  * [`ed15bbc`](https://github.com/8dmusichannels-star/terminator/commit/ed15bbc)

### 🐛 Fixed

* 📝 **Long Text Entry**

  * Fixed an issue where IMEI could become hidden while swiping left on the long-text entry page.
  * [`4e81c40`](https://github.com/8dmusichannels-star/terminator/commit/4e81c40)

* 🖥️ **Split-Screen Focus**

  * Fixed split-screen focus handling for `CTRL + ALT`.
  * [`1c14637`](https://github.com/8dmusichannels-star/terminator/commit/1c14637)

* 💥 **SIGKILL / CTRL + D**

  * Added/fixed `SIGKILL` handling and `CTRL + D` behavior when entering split-screen mode.
  * [`4e81c40`](https://github.com/8dmusichannels-star/terminator/commit/4e81c40)

* 📋 **Paste Toolbar**

  * Fixed the toolbar appearing unexpectedly during paste operations.
  * [`88b71ba`](https://github.com/8dmusichannels-star/terminator/commit/88b71ba)

* 🧩 **Split-Screen Sessions**

  * Fixed session handling and cleanup related to split-screen mode.
  * [`1c14637`](https://github.com/8dmusichannels-star/terminator/commit/1c14637)

### 🔧 Maintenance

* 🔄 Continued UI, session, keyboard and split-screen improvements across the development branch.
* 🧪 Multiple stability and interaction fixes included in this development cycle.
